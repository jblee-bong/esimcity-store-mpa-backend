갤럭시 (Android)

1
[설정] → [연결] → [SIM 관리자] → [eSIM 추가]
2
[QR 코드 스캔] 선택 후 전달받은 QR 스캔
3
현지 도착 후 [모바일 데이터]를 eSIM으로 지정하고 [데이터 로밍 ON]
• QR 스캔은 Wi-Fi 등 인터넷 연결 상태에서 진행해 주세요.
• 등록 완료된 eSIM 프로필은 절대 삭제하지 마세요 (삭제 시 재발급 불가).
• QR 스캔 후 로딩까지 시간이 걸릴 수 있습니다.

7. 자주 묻는 질문

Q.한국에서 미리 등록해도 되나요?
네. 출국 전 미리 QR을 스캔해 등록해 두시는 것을 권장합니다. 한국에서는 현지 네트워크가 연결되지 않으므로, 방문국 도착 후 eSIM 데이터를 켜고 데이터 로밍을 ON 하면 사용이 시작됩니다.
Q.현지에서 데이터가 안 터져요.
1) 기본 설정
• 아이폰: [설정] → [셀룰러] → eSIM 선택 → 데이터 로밍 ON / 셀룰러 데이터를 eSIM으로 선택
• 갤럭시: [설정] → [연결] → [모바일 네트워크] → 데이터 로밍 ON / [SIM 관리자]에서 주 모바일 데이터를 eSIM으로 선택

2) 재부팅 전원을 1~2회 재부팅해 주세요.

3) 네트워크 수동 선택 자동 연결이 안 되면 [네트워크 사업자]에서 자동을 끄고, 상품 안내의 현지 통신사를 직접 선택해 주세요.

4) APN 필요 시 알림톡/메일에 안내된 APN을 입력해 주세요.
그래도 안 되면 네이버 톡톡 또는 카카오톡 문의(@이심시티) 로 문의해 주세요.
Q.이용 기간은 언제부터 계산되나요?
현지 네트워크에 처음 연결되어 데이터가 되는 시점부터입니다. 한국에서 등록만 해둔 상태에서는 기간이 차감되지 않습니다.
Q.이미 사용된 코드라고 나와요.
한 번 등록된 QR은 재스캔이 불가합니다. [설정] → [셀룰러/모바일]에서 요금제가 이미 추가되어 있는지 확인해 주세요.
Q.eSIM 프로필을 삭제했어요.
eSIM은 1회성으로, 삭제 시 재발급·복구가 어렵습니다. 문제 시 삭제하지 말고 고객센터로 문의해 주세요.
